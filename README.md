# Wedding Planning Manager

A single-file wedding planning app — open `index.html` in a browser and it just works. No build step, no server, no dependencies.

## Features

- **Task checklist** with categories and filtering, so nothing falls through the cracks in the months before the big day
- **Budget tracking** alongside the tasks it pays for
- **Bilingual UI** — switch between English and 中文 at any time
- **JSON export** to back up or move your plan
- Runs entirely in the browser; your data stays on your device

## Run it

```bash
git clone https://github.com/Tommyz123/wedding-planning-manager
open wedding-planning-manager/index.html
```

That's it — one HTML file, vanilla JS/CSS inside.
